## ⚠️ Legal & Ethical Disclaimer

This repository is for education, authorized security testing, defensive research, and legal laboratory environments only.

Never test systems, networks, applications, accounts, or infrastructure without explicit authorization.

> **Learn legally. Test ethically. Document responsibly.**

---

## 🎯 Learning Philosophy

```text
Understand → Practice → Analyze → Build → Document → Improve
```

The goal is not to memorize tools. The goal is to understand **why systems work, how they fail, how to validate security weaknesses safely, and how to communicate remediation clearly.**

# 📚 Core References

- [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/latest/)
- [OWASP WSTG Stable](https://owasp.org/www-project-web-security-testing-guide/stable/)
- [NIST SP 800-115](https://csrc.nist.gov/pubs/sp/800/115/final)
- [MITRE ATT&CK](https://attack.mitre.org/)
- [PortSwigger Web Security Academy](https://portswigger.net/web-security)

The OWASP WSTG provides a structured framework for web application security testing, while NIST SP 800-115 covers planning, conducting, analyzing, and reporting technical security assessments. MITRE ATT&CK is useful for understanding adversary tactics and techniques.
