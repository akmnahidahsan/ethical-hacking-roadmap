# 📝 Security Reporting

## Finding Structure
```text
Title
Severity
Description
Affected Asset
Evidence
Technical Impact
Business Impact
Validation / Reproduction
Recommendation
References
Retest Status
```

## Severity
- [ ] Informational
- [ ] Low
- [ ] Medium
- [ ] High
- [ ] Critical

## Executive Summary
Explain:
- What was tested
- What was discovered
- Why it matters
- What should be done

## Retesting
```text
Finding → Fix → Retest → Fixed / Partially Fixed / Still Vulnerable → Final Report
```

Reference: [NIST SP 800-115](https://csrc.nist.gov/pubs/sp/800/115/final)
